# Kothuru Asini Landing Page

A futuristic, premium-quality landing page for **Kothuru Asini**, designed as a recruiter-friendly portfolio website with dark-mode glassmorphism, neon glow effects, smooth animations, and responsive layouts.

## Features

- Sticky futuristic navbar with active section highlighting
- Animated hero section with typing effect and social links
- Glassmorphism about, skills, projects, blog, resume, and contact sections
- Project filtering and modal preview
- Animated counters, skill bars, and scroll-triggered reveals
- Cursor glow, scroll progress bar, loading screen, and back-to-top button
- Responsive layout for desktop, tablet, and mobile
- Resume download button linked to a downloadable PDF asset

## How to Run Locally

1. Open `index.html` in your browser.
2. Or use a simple local server, for example:

```bash
npx serve
```

## GitHub Repository Setup

Run these commands from the project folder:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin <your-repository-url>
git push -u origin main
```

If the repository already exists on GitHub, replace `<your-repository-url>` with the actual remote URL.

## GitHub Pages Deployment

1. Push the code to GitHub.
2. Open the repository in GitHub.
3. Go to **Settings** > **Pages**.
4. Select the branch: `main`.
5. Choose the root folder `/`.
6. Save the settings and wait for GitHub Pages to publish the site.

## Netlify Deployment

1. Push the project to GitHub.
2. Sign in to Netlify.
3. Choose **Add new site** > **Import an existing project**.
4. Connect the GitHub repository.
5. Keep the default build settings for a static site.
6. Deploy the site and copy the generated live URL.
